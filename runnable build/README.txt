Location Tracker — runnable Android build
========================================

File:
  location_tracker-release.apk

Install on Android:
  1. Copy the APK to your phone (USB, Drive, AirDrop via companion, etc.)
  2. Open the file and allow install from this source if prompted
  3. Or from a machine with adb:
       adb install -r location_tracker-release.apk

Notes:
  - Built with Flutter release mode
  - Signed with the debug keystore (fine for assignment / local testing)
  - iOS IPA is not included here (needs Apple Developer signing)

This folder is listed in .gitignore and is not pushed to GitHub.
